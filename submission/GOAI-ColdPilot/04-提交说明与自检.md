## 事实与口径自检

- 当前系统是可运行的 React + FastAPI 全栈 MVP。
- 默认 Agent 为离线确定性 Agent；OpenAI 兼容 LLM 仅为可选诊断综合模式。
- 五类工具调用和结构化输入输出均由后端执行并留痕。
- 候选控制方案当前来自演示种子数据，不宣称由大模型动态生成。
- 执行为仿真曲线回放，尚未接入真实 PLC 或边缘网关。
- 所有能耗、恢复时间、置信度和业务效果均标注为演示或仿真，不作为真实试点成效。
- 当前没有真实客户、试点、节能率、货损降低率或诊断准确率证据。
- L2 人工审批、L3 永久拦截、执行前二次安全校验和方案版本绑定已有代码实现。

## 演示建议（3 分钟）

1. 首页等待审批：说明 Agent 已自主完成诊断、仿真与安全检查，并在 L2 节点停下。
2. Agent 工作台：展开五类工具调用，展示原因排序、支持证据和反向证据。
3. 策略与仿真：对比 A/B 方案的恢复时间、能耗和风险，强调结果为仿真。
4. 首页安全卡：展示 L3 联锁绕过动作被永久拦截。
5. 批准并执行：展示结构化命令、执行监控、效果验证和恢复报告。
